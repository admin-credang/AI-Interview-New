Live Interview Guard - accuracy dashboard (precision / recall / F1)

Goal: measure how often the proctor is right, and how often it raises a false alarm on an honest candidate. Everything runs in this page; nothing is uploaded.
1) Record several consented mock interviews where YOU know what happened (normal thinking, phone beside the laptop, notes, second monitor, helper speaking, phone in hand). 2) Load each report .json. 3) Pick the scenario and write what really happened, one per line like 01:15 phone_beside_laptop (leave EMPTY for an honest "normal thinking" recording: every flag then counts as a false alarm). 4) Calculate.
