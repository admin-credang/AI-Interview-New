Privacy & Consent

The no-install Live Interview Guard runs in the interviewer's browser.

  • Video: the selected meeting tab/window video is analysed in the browser for face presence, eye movement and phone-like objects. Raw video frames are not uploaded by this page.
  • Audio sources: the local microphone is assigned to the interviewer; shared meeting-tab audio is assigned to the remote candidate. This assumes the interviewer is using this computer and the candidate is remote.
  • Speech recognition: the page uses the browser's Web Speech recognition API on those audio tracks. Depending on the browser, speech recognition may send audio to the browser vendor's speech service for transcription. This is not guaranteed to be offline.
  • Transcript and report: recognised text is held in this page while the interview runs. When the interview ends, an HTML report is downloaded to the interviewer's computer. The report can be printed or saved as PDF.
  • No project backend: this no-install mode does not send the transcript to a custom project server or store it in a cloud database.
  • Candidate consent: the interviewer must notify the candidate and obtain consent before sharing, transcribing or assessing meeting audio/video.

Speech source classification can be affected if remote candidate audio leaks into the interviewer's microphone. Headphones are recommended. If the browser does not provide a shared tab audio track, candidate speech cannot be captured automatically.

Webcam findings are indicators only, not proof of misconduct. The report does not make hiring decisions.
